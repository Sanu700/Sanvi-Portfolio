# 🌸 Sanvi Udhan — Developer Portfolio

> **Personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.** Dark theme with pink/purple/blue gradient accents, cinematic scroll animations, and a premium glassmorphism UI.

## ✨ Sections

- **Hero** — Typing animation, floating avatar, availability badge, social links
- **About** — Story blocks, stats grid, BITS Pilani card
- **Skills** — Auto-scrolling icon carousel + categorised skill cards
- **Projects** — Bento-style layout with featured cards, hover glow effects, animated modals
- **Journey** — Alternating vertical timeline with scroll animations
- **Contact** — Glassmorphism form + social links + availability indicator

---

## 🚀 Getting Started

```bash
git clone https://github.com/Sanu700/Sanvi-Portfolio.git
cd Sanvi-Portfolio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## 🎨 Design System

- **Background** — Deep `#0d0a1a` with persistent pink/purple/blue radial gradient blobs
- **Accent colours** — Pink `#f472b6` · Purple `#c084fc` · Blue `#60a5fa`
- **Glass cards** — `backdrop-filter: blur(14px)` with subtle gradient borders
- **Typography** — Pacifico for display, Poppins for body
